# 从本地 Workspace 开始

Verdlen 的基础原则是：**个人内容即使没有购买 Cloud，也应继续在创建它的设备上可用。** 登录账号、购买云服务、启用同步和加入团队是不同的决定。

## 1. 登录前也能创建内容

创建 Page 并编辑内容。本地持久化成功和远端同步成功是两个状态，界面不能把“网络请求已经排队”显示为“全部同步完成”。

## 2. 同步需要明确选择

登录只负责确认账号身份，不应该自动把所有本地内容变成服务器权威副本。启用同步时，再建立远端所需的数据和权限关系。

## 3. 团队内容遵循当前权限

Team 内容即使曾经缓存到设备，也不会因此变成个人永久副本。成员被移除后，服务端先阻止新的访问，客户端随后锁定并清理对应作用域的缓存和派生数据。
